# 賃貸物件探しの王道 / 未公開物件 / REINS・ATBB (調査メモ)

調査日: 2026-11-12。信頼度: [V]=ページ本文を実際に読んで確認, [S]=検索スニペット/ツイート本文のみ。
範囲: 正規ルートと制度の事実のみ。REINS/ATBBへの不正アクセス・認証回避・ID貸借は調査対象外。

## 1. 未公開物件とは

種類 (実務上の整理。ツイート/制度からの推論を含む):
1. 掲載前 (先行募集): 退去予定/退去直後で、ポータル掲載前に仲介会社間や常連に出る。
   - 「退去前から募集が始まり、内見できる頃には申込みが入っていることもある」 https://x.com/Kouichi_I01/status/2120356786293387730 [V 本文] (不動産会社経営者)
   - 「先行申込・先行契約主流だから…掲載する必要がない」 https://x.com/doemnoinu/status/2118210279842754641 [S]
2. ポータル非掲載 (掲載枠コスト/業者間のみ):
   - 「ポータル離れが凄い…賃貸仲介時代から一切ポータル使ってない。ATBBだけは基本料金で」 https://x.com/toyoko_taro/status/1750448161049760072 [V 本文] (投稿者は不動産関係者を示唆するが、プロフィールは東横線ファンで要注意)
3. 業者間のみ (REINS/ATBB/イタンジBB等): 一般には見えない。
   - 「賃貸仲介会社、営業中は常にレインズATBBイタンジ更新ボタン押し続けてるし、仲の良い管理会社から事前情報もらって夜間帯の募集開始を待ち構えてる」 https://x.com/peremeten/status/1994570182820597936 [V 本文] (24 likes, 不動産会社勤務と思われる)
4. 大家・管理会社だけが持つ (自社管理の空室): 管理会社の店舗/サイトのみ。「古くからやっている不動産会社に直接行く…ホームズやスーモは情報が遅く、良い物件は公開される前に取られている可能性」 https://x.com/XioMancow/status/2118183581801644419 [S] (一般ユーザー, 信頼度低)

誇大宣伝の見分け方:
- 「未公開」はプレミア感で成約率を上げる営業手法。「ネットなどに公開されていないというだけでプレミア感が高まり…成約率が高まります」 https://x.com/Kg1lBQaKY8ydQ3l/status/2119705172054303035 [V 本文] (現役住宅営業, 37 likes。土地の話だが心理は同じ)
- 業界側の見方: 「レインズは売れ残りだろ？」と言う客への反論 https://x.com/x17OFpZPuN43732/status/2025577069447700715 [S]
- 結論: 賃貸の「未公開」の実態は「ポータル掲載前の鮮度の高い情報」か「業者間サイトにだけある物件」で、特別な掘り出し物とは限らない。具体的物件名・家賃・住所を出さずに「未公開あります」とだけ言う来店誘導は警戒 (推論)。

## 2. REINS / ATBB / 業者向けサイト

REINS:
- 宅建業法に基づき国土交通大臣が指定する「指定流通機構」(全国4機構)が運営、全国の不動産業者が加入。 http://www.kinkireins.or.jp/reins/ [V]
- 首都圏(東京・神奈川)は東日本レインズ。公式サイト https://www.reins.or.jp/about/ は取得不可(接続エラー)。 [S: 「会員の不動産会社が…『貸したい方』からの依頼内容をもとに物件情報を登録」]
- 法定登録義務は専任/専属専任媒介の「売買又は交換」のみ。賃貸には宅建業法34条の2の登録義務なし。 https://laws.e-gov.go.jp/api/1/lawdata/327AC1000000176 (第34条の2第1項/第5項) [V]。そのため賃貸は元付会社の運用次第でREINS/ATBB/他サイトに分散。 例: 「賃貸客付けで…ちゃんとレインズ載せてくれる/マイソクを正しく作る/囲い込まない元付を選ぶ」 https://x.com/mato_chance/status/1560763679250989056 [V 本文] (大阪・兵庫の宅建業社長)
- 利用規程(近畿レインズ抜粋): 会員は情報を元付業者の承諾なくネット広告・チラシ等に掲載してはならない。また媒介など宅建業目的以外で利用して利潤を得てはならない。 http://www.kinkireins.or.jp/koukoku/ [V] → REINS物件がそのままポータルに出ない理由、かつ第三者(非会員)への画面提供が想定されていない根拠。
- 一般人が見られるもの: (a) 専任/専属専任で売却を依頼した売主の専用物件確認画面(売却側のみ), (b) 成約価格のRMI(売買が中心)。 https://www.facilo.jp/blog/reins-bukkenkensaku/ [V], https://www.contract.reins.or.jp/ [V: RMIは国交省の不動産情報ライブラリ「成約価格情報」に移行、サイトは休止中]。 賃貸の募集物件検索には使えない。
- 一般人が業者用レインズのアカウントを作ることはできず、「不動産会社へ希望条件を伝え、紹介を受ける」が正規ルート。 https://www.facilo.jp/blog/reins-bukkenkensaku/ [V]

ATBB:
- アットホームの加盟店向け業務支援/情報流通サービス(登録・公開(B2B)、検索・入手、消費者向け公開(B2C))。ATBB賃貸/売買があり、利用にはアットホームへの入会が必要。 https://business.athome.jp/service/atbb/ [V]。「63,000店以上が加盟」(同ページ)
- 物件ステータス(募集準備/募集中/申込対応中/契約準備/成約済)の5段階管理、「リアクション表示」(客付会社の閲覧・保存) https://business.athome.jp/service/atbb/ [V]
- 消費者向けの対応サービスはアットホーム(athome.co.jp)。 加盟店が公開した物件がB2Cに載る仕組み。
- 他の業者間サイト: イタンジBB, いえらぶBB 等 https://x.com/kanriya_gakumon/status/2009838309472899509 [S]

非会員が正規に恩恵を受ける方法:
1. 仲介会社に条件を伝え、REINS/ATBB等の検索を代行してもらう(「レインズ見せてくれるかは不動産会社次第」 https://x.com/CS20220330ryo/status/1960673992869863614 [V 本文] ※非宅建士)。
2. 「ネット上に出ていない物件を、不動産業者専用データベースからご紹介」: ietty (宅建免許業者が運営、仲介手数料最大50%OFF、原則家賃6万円以上、東京23区+川崎/横浜一部) https://ietty.me/ [V]
3. 物件リクエスト/逆オファー系: ietty (登録条件で提案), ウチカツ (一般人と不動産業者の無料マッチングSNS) https://x.com/uruhome_net/status/1691994648062185761 [S], ウチコミ「賃貸物件リクエスト」(オーナー向け側の観点) https://x.com/invest_run/status/1943438666740961651 [S]
4. 管理会社/大家の直接募集、UR(礼金・仲介手数料・更新料なし。希望条件のメール通知サービスあり=子育て世帯・若者夫婦限定) https://www.ur-net.go.jp/chintai/ [V]
5. 禁止/避けるべき: 知人の宅建業者に画面を見せてもらう・IDを借りる等は規程の趣旨(会員が宅建業目的でのみ利用)に反する。依頼する場合は正式に仲介を依頼する。

## 3. 王道・賢いやり方

- 好条件は数日で決まる。 https://x.com/manarisu/status/2120088011761439230 [V] / 「募集開始から終了まで3時間」(レインズで見つけた例) https://x.com/rightperson151/status/2119236789756121273 [V 本文, 一般ユーザー]
- ポータルを見て、条件を決め、複数候補を空き確認→期間を空けず内見・申込。複数申込できるなら複数。 https://x.com/zfMMxcczmP0RMKC/status/1814888445753635140 [V 本文] (賃貸仲介の個人事業者アカウント, 19 likes)
- 仲介の中の人は常にREINS/ATBB/イタンジを更新、管理会社から事前情報、夜間募集を待つ → ネットだけで比較するより早く不動産屋へ。 https://x.com/peremeten/status/1994570182820597936 [V 本文]
- ポータルURLを仲介に送り「似た条件も含めて」相談。 https://www.facilo.jp/blog/reins-bukkenkensaku/ [V] (売買記事だが賃貸にも適用可)
- 先行契約・居住中: 内見できず写真は過去のものの可能性。キャンセル待ち手数料の請求例も。 https://x.com/Kouichi_I01/status/2120356786293387730 [V], https://x.com/DeliverySato/status/2119788682958008457 [V 本文]
- 時期: 12月までは交渉余地、1-3月は繁忙期で強気。 https://x.com/honnefudousan/status/2120094124129075569 [V 本文] (賃貸仲介会社中の人アカウント, 36 likes)
- 初期費用/手数料: ADは貸主が仲介会社へ払う広告料(法律用語ではない)。借主の手数料上限はADの有無で同じ。 https://x.com/tomita_shumpei/status/2119267001898250599 [V 本文] (不動産鑑定士)。 手数料無料はADモデル。他店で内見・申込後に無料店へ「仲介飛ばし」するのは嫌われ審査に影響し得る。 https://x.com/KoyaTsukamoto/status/1633142098722721792 [V 本文] (賃貸仲介業者)。 ietty等の手数料割引は店舗コスト削減がうたい文句。
- 審査: オーナー審査もあり、申込書の字を丁寧に。 https://x.com/tkworks88/status/2119928022908240212 [V 本文]
- 仲介飛ばし/囲い込み注意: 元付がレインズに載せない・載せても他社を案内しない。 https://x.com/mato_chance/status/1560763679250989056 [V 本文]

おとり広告の規制 (事実, 一次資料):
- 不動産の表示に関する公正競争規約 第21条: (1)物件が存在しない, (2)存在するが取引の対象となり得ない(成約済み等), (3)取引する意思がない物件の広告を禁止。公取委告示(昭和55年第14号)で非会員にも適用。 https://www.rftc.jp/webkanri/kanri/wp-content/uploads/2019/11/20191106-otori-guideline.pdf [V]
- ネット広告の情報更新は最長でも2週間。契約済みはすみやかに削除。「情報登録日又は直前の更新日及び次回の更新予定日」の表示義務あり。 同PDF [V]
- 意思がない例: 「合理的な理由がないのに案内を拒否」「難点をことさら指摘して他物件を勧める」 同PDF [V]。 実害: 来店後「さっき申込みが入りました」 https://x.com/roomxh/status/1979658565741928565 [S, 77 likes, チェックシートはリプ欄で未取得]
- 対策: 問い合わせ時に「この物件の募集状況(物確)を今確認して」と聞き、更新日・次回更新予定日を確認。掲載日時と家賃が相場より異常に安い物件に注意。通報先は各地区の不動産公正取引協議会(首都圏は首都圏不動産公正取引協議会) https://www.rftc.jp/ [V]

## 4. 自動化との相性 (東横線・目黒線 1LDK ツール向け)

- 鮮度が全て。募集開始〜終了が数時間のケースもあるため、監視頻度と通知速度が価値。ポータルは「更新頻度最短5分」(CHINTAI) https://www.chintai.net/ [V]。 SUUMOは会員の「希望条件登録」「新着メルマガ」 https://suumo.jp/chintai/ [V]、Yahoo!不動産は「物件の新着情報をLINEでいち早く」「保存した検索条件」 https://realestate.yahoo.co.jp/rent/ [V]。 保存検索のメール/LINE通知を複数ポータルで並行して受ける。
- 表示規約により広告ページには「情報登録日(または直前更新日)」「次回更新予定日」の表示義務 → 取得できればデータ化し、古い情報(2週間超)・重複・消えた物件を除外するフィルタに使える。 https://www.rftc.jp/webkanri/kanri/wp-content/uploads/2019/11/20191106-otori-guideline.pdf [V]
- 同一物件の複数ポータル重複排除(住所/築年/階/面積/家賃のキー)。同一物件が管理会社ごとに別広告で出るため。
- 「消えるまでの時間」を記録 → 実質のおとり率や人気度を指標化。
- 自動化の限界(推論): 業者間情報は取得不可。取れるのは公開ポータルの情報のみ。最終確認は電話/チャットでの空き確認。各サイトの利用規約・robots・アクセス頻度(athomeは高頻度リクエストでブロックを確認 https://www.athome.co.jp/chintai/ [V])に注意し、公式の保存検索通知やRSS/メールを優先する。
- 沿線特化: 東横線・目黒線沿線の地場不動産と管理会社の一覧化 → 直接電話の候補リスト(ツール外運用)。ietty(23区+川崎/横浜一部)やURの条件通知は補完ルート。
